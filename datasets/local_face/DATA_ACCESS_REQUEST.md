# Dataset access request

Send the following information to `faizanshirazi@neduet.edu.pk`.

```text
Subject: Local face dataset access request

Name:
Institution:
Institutional email:
Project title:
Research purpose:
Expected completion date:

I have read DATA_USE_TERMS.md. I agree not to redistribute the dataset or
password, attempt to identify participants, use the data for face recognition,
or use the data outside the approved research purpose.
```

Access is not automatic. The dataset owner may request additional information
before supplying the password.
